# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities with friends using WhatsApp, Facebook, X, or a copied link

## Sharing an activity

Use the sharing buttons below an activity to send it to a friend. **Copy link**
lets you paste its link into any message or email. On supported phones and browsers,
**More...** opens your device's sharing menu. If automatic copying is unavailable,
select and copy the link displayed below the buttons.

Shared links highlight the activity when opened. Only the activity name and link
are shared, never student details. Social sites open only when you select their
button. Friends need access to the website; a localhost link only works on your
own computer.
